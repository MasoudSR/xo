🎮 XO: TicTacToe Remake<br>
This is a remake of the classic TicTacToe game I previously developed. Now with enhanced features, a more modern design, and added functionality like AI opponent and online gameplay!

You can check out the original version of the game here:<br>
Play the original game:🌐<a href="https://tictactoe.masoudsr.ir/">tictactoe.masoudsr.ir/</a><br>
View the original game source code:[github.com/MasoudSR/tictactoe](https://github.com/MasoudSR/tictactoe)

![XO Screenshot](./screenshots/screenshot1.png)

Features:<br>
🤖 Play against AI: Challenge yourself with different levels of AI difficulty.<br>
👥 2-Player Matches: Play with your friends either offline or online.<br>
💬 In-game Chat: Communicate with your friend while playing online.

![XO Screenshot](./screenshots/screenshot2.png)

Demo:<br>
Play the remake here: 🌐[xo.masoudsr.ir](https://xo.masoudsr.ir/)

Technologies Used:<br>
React.js: For building the user interface.<br>
TailwindCSS: For responsive and modern design.<br>
PeerJS: For enabling real-time peer-to-peer online matches
